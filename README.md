# طرح ۴ — شبکه خورشیدی آینده | برقتو

**Cinematic dark-mode Persian solar aggregation landing-page concept.**

> **نوع پروژه:** طرح مستقل UI/UX و فرانت‌اند استاتیک، مناسب بررسی و مقایسه ایده‌های طراحی؛ نه سامانه عملیاتی فروش یا پایش برق.

## هدف طراحی

طراحی سینمایی و تیره با روایت شبکه خورشیدی آینده. این طرح برای بررسی زبان بصری و روایت دیجیتال خدمات تجمیع برق خورشیدی برقتو ایجاد شده است.

## عناصر شاخص

- هدر و بخش آغازین با فضای تیره و تمرکز بر مزیت درآمد نیروگاه
- بخش‌های ارزش افزوده، پایش تولید و فرآیند فروش
- محاسبه‌گر نمونه بر اساس ظرفیت نیروگاه
- فرم سمت مرورگر که تنها پیام نمایشی نشان می‌دهد

## فناوری و فایل‌ها

- **HTML / CSS / JavaScript** — کد این نسخه در فایل `index.html` تجمیع شده است.
- **کتابخانه‌ها و منابع:** فونت Vazirmatn، GSAP، ScrollTrigger و Lenis از CDN.
- رابط فارسی راست‌به‌چپ، مناسب مشاهده در مرورگرهای جدید.

## اجرای محلی

از ریشه مخزن، فایل `index.html` را در مرورگر باز کنید. برای پیش‌نمایش با سرور استاتیک:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000/` را باز کنید. نیاز به npm، دیتابیس یا فرآیند Build نیست. انیمیشن‌ها و فونت‌های CDN برای نمایش کامل نیاز به اینترنت دارند.

## محدودیت‌ها و ملاحظات

- فرم شماره تلفن، داده‌ای را برای بک‌اند ارسال نمی‌کند؛ متن موفقیت فقط در مرورگر نمایش داده می‌شود. ارقام محاسبه‌گر نمونه‌اند.
- محاسبه‌های مالی/فنی و آمار باید قبل از استفاده واقعی با داده معتبر راستی‌آزمایی شوند.
- برای اتصال فرم‌ها به CRM، احراز هویت، ثبت داده و مدیریت اطلاعات شخصی به بک‌اند ایمن نیاز است.
